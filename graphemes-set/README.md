# Readme

The scripts in this directory format the FirstVoices data from the [First-Peoples-Cultural-Council/unicode-resources GitHub repo](https://github.com/First-Peoples-Cultural-Council/unicode-resources) into CSV files that represent standard grapheme sets. Data can be read live from GitHub or from a local copy.

## Install

- Use the Node.js version specified in `.nvmrc`
- `npm i` to install the script dependencies from `package.json`

## Environment variables

- Make a copy of `.env.sample` called `.env` - this will be used by the live GitHub scripts in `package.json`
- In `.env`, add a GitHub Personal Access Token that has permissions to read public repositories
- Local-copy scripts do not use the GitHub API or require a token. See [input/README.md](./input/README.md) for instructions to populate the ignored dataset directory.

## Run

- `npm run start:full` to run against live GitHub data with all alphabet columns, writing `output/live-github/alphabet-output-full.csv`
- `npm run start:compact` to run against live GitHub data with minimal alphabet columns, writing `output/live-github/alphabet-output-compact.csv`
- `npm run start:unique` to run against live GitHub data and write one row per unique Unicode code point to `output/live-github/unique-characters-output.csv`
- `npm run start:full:local-copy` to run the full format against `input/orthography-resources`, writing `output/local-copy/alphabet-output-full.csv`
- `npm run start:compact:local-copy` to run the compact format against the local copy, writing `output/local-copy/alphabet-output-compact.csv`
- `npm run start:unique:local-copy` to run the unique-character format against the local copy, writing `output/local-copy/unique-characters-output.csv`

The full and compact commands also generate `confusables-output.csv` in the matching source output folder. Unique-character commands do not generate confusables output.
The remaining column descriptions below apply to each source-specific output folder.

## Tests

- `npm test` or `npm run test:local` runs the local fixture and utility tests without network access.
- `npm run test:local-copy` checks that every character in each `input/orthography-resources/*/alphabet_ordering.csv` is present in `output/local-copy/unique-characters-output.csv`. It fails with a clear message if the input data or output file is missing; run `npm run start:unique:local-copy` first to generate the output.
- `npm run test:live-github` runs the live GitHub coverage test against the current `output/live-github/unique-characters-output.csv`. It requires a network connection; set `GITHUB_TOKEN` in `.env` to reduce the chance of rate limiting.

## Output CSVs columns

### `alphabet-output-full.csv`

- `Character`: the grapheme as it was pulled from the `unicode-resources` repo
- `NFD`: [Unicode Normalization Form](https://unicode.org/reports/tr15/) D (Canonical Decomposition)
- `NFC`: Unicode Normalization Form C (Canonical Decomposition, followed by Canonical Composition)
- `NFD Escaped`: Escaped Unicode string representation of the NFD grapheme
- `NFC Escaped`: Escaped Unicode string representation of the NFC grapheme
- `NFD Code Points`: Unicode code point representation of the NFD grapheme (space-separated)
- `NFC Code Points`: Unicode code point representation of the NFC grapheme (space-separated)
- `AnyAscii`: ASCII representation of the grapheme generated by [AnyAscii](https://github.com/anyascii/anyascii)
- `Languages`: Indigenous language(s) that the grapheme comes from (mapped using [`firstvoices_sites_metadata_2025.csv`](https://github.com/First-Peoples-Cultural-Council/unicode-resources/blob/main/orthography-resources/firstvoices_sites_metadata_2025.csv)) (comma-separated)

### `alphabet-output-compact.csv`

- `Language Name`: language name mapped from the FirstVoices site metadata
- `Character`: alphabet character in the order listed by that language's `alphabet_ordering.csv`
- `Unicode Hex`: Unicode code points for the character, formatted as space-separated `U+XXXX` values
- `Character Variant`: an equivalent variant from `character_variants.csv`, when available
- `Character Variant Unicode Hex`: Unicode code points for the variant, when available

Each row represents a language, character, and variant combination. Characters without variants have empty variant columns; characters with multiple variants have one row per variant. Rows are grouped by language name. The compact output is intended to support language-specific character testing, including BC Sans font coverage.

### `unique-characters-output.csv`

- `Character`: one Unicode character found in the First Voices data; composite source characters are split across rows
- `Unicode hex`: the character's Unicode code point, formatted as `U+XXXX`

Characters are sorted by Unicode code point order. This output supports reviewing the complete set of characters for BC Sans font coverage.

### `confusables-output.csv`

- `Confusable`: the alternate grapheme observed in `confusable_characters.csv`
- `Canonical Character`: the canonical grapheme linked to the confusable
- `Languages`: Indigenous language(s) where that exact confusable/canonical pair appears (comma-separated)
